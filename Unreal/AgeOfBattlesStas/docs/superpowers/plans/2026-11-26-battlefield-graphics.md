# Battlefield graphics improvement plan

The approved checklist is the 20-point battlefield graphics proposal in the conversation, plus multiple horse coats and human skin tones. The work uses the existing Low Poly assets, materials, instance batches, terrain data and effects. Gameplay, scenario rules, unit stats and existing missions are preserved.

- [x] Lighting and terrain (1–13). In RegimentMarchBoard and its presentation helpers, align exposure in all battlefield cameras, rebalance existing sunlight and sky fill, and tune map palettes and non-volumetric haze. Improve broad terrain color, seam blending, road ruts, slope colors, water movement, ford, woodland variety, distant landmarks, and the redoubt cross section. Keep existing collision and terrain passability. The geometry tests passed, including level exterior water for Narva.
- [x] Figures (14–18 and additional variation). Refine surfaces for fabric, wood and metal, give figures seven skin tones and six horse coats selected by stable unit ID, and preserve these in the two detail tiers. Improve lower-detail silhouettes, animate nearby standards gently, and decorrelate visual gait phase. Existing proxy instance batches upload color data only when it changes. Figure appearance and motion tests passed.
- [x] Effects (19–20). Distinguish firearm volley and artillery smoke using existing combat events and render pools. Add nearby dry-terrain cavalry dust at regiment granularity. Cull by visual budget and camera distance, with no modification to simulation. The test suite covers smoke sources, camera range, occlusion, wet ground, fadeout and the fixed pool limit.
- [x] Integration. The previous Shipping build supplied the baseline. The final Unreal automation run passed 87 tests. The final Windows build was launched and screenshots were recorded in `Saved/BuildVerification/GraphicsPass`. The four new material masters were verified in the staged IoStore container. The Windows x64 installer version is 2026.11.26.5.

The release cook uses versioned packages written directly to the local drive with `-VersionCookedContent` and `-SkipZenStore`. Keeping figure material state outside the serialized actor layout preserves existing maps. The loose cook made all four graphics masters available to the staged build.

The before/after comparison ran 500 ticks with 5,000 figures in each of two camera modes and two historical fixtures on the RTX 3070. Simulation hashes matched for every paired run. Recorded game-frame times and individual windows are in `Saved/BuildVerification/GraphicsPass/comparison.csv`.
