# Каталоги восьми эпох

У полка есть профиль, назначенный фракцией. В конном полку можно выбрать другую
доступную лёгкую или тяжёлую конницу. У стрелков пешего полка можно выбрать
доступное вооружение. Стрелки в одном полку используют один профиль. Имена,
описания, тип оружия и параметры каждого профиля находятся в `module.json`.

В папках `01_ancient`–`08_fantasy` по одному версионированному манифесту на эпоху.
`mission.terrain` задаёт карту встроенной миссии и по умолчанию использует `OpenField`.
`factions[].visual` выбирает форму головных уборов и окраску поверх общих фигурок.
Отдельные миссии лежат в `Content/Battle/HistoricalPresets` и привязаны к ID и версии модуля.

Тип `gunpowder` подходит для ранних аркебуз, `musket` даёт штыковую атаку,
`arcane` даёт магический снаряд с расходуемыми зарядами. Каждый стрелковый профиль
задаёт боезапас, дальность и время перезарядки. Платформа `field_gun` использует
тот же интерфейс отряда, что метательные машины, и добавляет прямую стрельбу с дымом.

## Настольные правила и цифровая адаптация

- Боезапас считается на воина. В §35 руководства установлено 8 выстрелов для
  пешего лучника и арбалетчика и 3 для метателя дротиков. Пращникам назначено
  8 выстрелов по игровому балансу.
- Скорость, дальность, прочность и урон заданы в единицах BattleCore. Дистанции
  и время перезарядки подобраны для масштаба игрового поля. Лёгкая конница
  быстрее, тяжёлая лучше защищена и сильнее при первом контакте. У конницы
  сохранены численность, позиции и прежний профиль фракции по умолчанию.
- Доступность архетипов задана для фракций эпохи. Балеарские пращники и
  нумидийские всадники представлены у Карфагена по описанию войска Ганнибала у
  Полибия. Отдельные профили рыцарей, конных сержантов и арбалетчиков опираются
  на образец ЛБХ ливонского войска.
